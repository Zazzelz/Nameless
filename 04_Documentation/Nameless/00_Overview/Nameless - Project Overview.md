## Project Summary
_Nameless_ is a folklore-inspired rogue-lite in which the player controls an otherworldly being navigating a magical game. Through their puppet adventurer, players explore mystical nodes, solve puzzles, and battle bosses with dice-and-card mechanics, collecting cards to grow stronger. The game combines strategy, problem-solving, and exploration with a mystical, eerie folklore atmosphere, ultimately leading to a confrontation with the Nameless Stitch, the originator of the game’s deadly wager.
## Core Goals & Vision
- Build a functional MVP with:
  - First exploration node
  - One boss encounter with phased combat
  - Dice + card mechanics implemented
- Capture a mystical, semi-realistic painterly aesthetic with bioluminescent flora and subtle magical effects
- Create a modular system for bosses, cards, nodes, and environments to allow scalable expansion
